# Full project zip (with models), in 4 parts

`circuit_identification.zip` is 353 MB, but GitHub accepts at most 100 MB per file.
So it is stored here split into 4 parts. Joining them gives back the
**exact original zip** (SHA-256 `4ef5e88f3d91b18a6010f15fd850a0f899510b6d426d88c0b23affbae8d39d11`).

## Steps

1. Download all 4 parts into the same folder (open each file, then click **Download raw file**):
   - `circuit_identification.zip.001` (90 MB)
   - `circuit_identification.zip.002` (90 MB)
   - `circuit_identification.zip.003` (90 MB)
   - `circuit_identification.zip.004` (67 MB)

   Or download the whole repo: **Code → Download ZIP**, which includes all parts.
2. Join them:
   - **Windows:** put `JOIN_PARTS_WINDOWS.bat` in the same folder and double-click it.
   - **Any OS:** `python join_parts.py`
   - **7-Zip:** right-click `circuit_identification.zip.001`, then 7-Zip, then Extract. 7-Zip joins the parts by itself.
3. Extract `circuit_identification.zip` to `C:\projects`, then follow the main README.
